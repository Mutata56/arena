Консольные отчёты по складу почти всегда рисуют рамкой: так глаз цепляется за нужный
блок. Сделай метод, который оборачивает строку в рамку.

Метод `Frame.box(String text)` возвращает три строки, склеенные переводом строки `\n`:

```
+--------+
| привет |
+--------+
```

Правила:

- верхняя и нижняя строки одинаковые: плюс, дефисы, плюс;
- дефисов ровно на два больше, чем символов в тексте, потому что по краям стоят пробелы;
- в конце результата перевода строки нет;
- пустой текст тоже рисуется, рамка просто получается маленькой.

Метод `main` пусть печатает пример: полезно увидеть результат глазами, а не только
зелёным тестом.
