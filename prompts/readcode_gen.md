## Что нужно

Ровно {{count}} задач. В каждой сниппет Java и один вопрос по нему с четырьмя
вариантами ответа.

Два рабочих типа вопроса, тип пиши в поле `kind`:

- `"output"`, «что выведет этот код»: в вариантах правдоподобные выводы, включая тот,
  что получится при типичной ошибке в рассуждении;
- `"bug"`, «где здесь баг»: код выглядит рабочим, но в нём одна конкретная ошибка,
  и варианты называют разные места.

Хорошо, когда типы перемешаны, а не все задачи одинаковые.

Требования к сниппету:

- код осмысленный, будто вырван из настоящего проекта, а не «класс A с методом f»;
- от 5 до 25 строк, без импортов сверх java.util;
- никаких хеш-кодов, времени, случайных чисел и порядка обхода HashMap;
- никаких многопоточных гонок: ответ должен быть воспроизводимым.

## Задачи типа output проверяются запуском

Сниппет типа `"output"` компилируется и запускается на самом деле, а его вывод
сравнивается с тем вариантом ответа, который ты пометил Клиент A. Не сойдётся,
задача выбрасывается. Поэтому:

- код это ЦЕЛАЯ программа: `public class Snippet` с методом
  `public static void main(String[] args)`. Никаких обрывков без класса;
- Клиент A вариант ответа это ТОЧНЫЙ вывод программы, слово в слово. Несколько строк
  вывода разделяй `\n` внутри строки варианта. Никаких пояснений внутри варианта,
  никаких кавычек вокруг, только сам вывод;
- остальные три варианта тоже выглядят как вывод, но ни один из них не совпадает
  с настоящим;
- программа печатает две-четыре строки: одна строка это слишком мелкий вопрос,
  десять уже не влезают в вариант ответа.

Для типа `"bug"` кода с классом не требуется, там достаточно фрагмента,
и варианты называют место ошибки словами.

Примеры бери из обычной жизни: покупки и чеки, расписание, оценки, список дел,
температура за неделю, имена и пароли, счёт в игре. Никакой специфики предметной области:
складские ячейки, паллеты и волны отбора человеку со стороны ничего не говорят, а разбирать
он должен язык, а не чужую отрасль.

## Форма записи

```
{
  "kind": "output",
  "code": "public class Snippet {\n    public static void main(String[] args) {\n        ...\n    }\n}",
  "question": "что выведет этот код?",
  "opts": ["точный вывод", "вывод при типичной ошибке", "третий вариант", "четвёртый"],
  "ans": 0,
  "exp": "разбор: что происходит по шагам и почему вывод такой",
  "topic": "короткая тема, два или три слова",
  "lvl": 1
}
```

Внутри `code` можно всё, что есть в Java, включая лямбды со стрелкой:
запрет на стрелки касается человеческого текста, а не исходников.
